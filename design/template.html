Wer soll auf deinem Terminal wohnen?

Vierzehn Entwürfe für das Pet, das auf den Textzeilen von Claude Code herumläuft. Probier sie in der Szene aus, zieh sie mit der Maus herum und sag Claude dann im Terminal, welche Nummer es werden soll.

Jede Textzeile ist Boden, das Zeilenende eine Kante. Neue Ausgabe schiebt den Text nach oben und trägt die Figur mit. Greif sie und wirf sie. Die neugierige Figur läuft deinem Zeiger nach, die ängstliche dreht an Kanten lieber um.

So unterscheiden sich die Charaktere

  • Faul: halb geschlossene Augen, gedeckte Farben, schläft viel
  • Neugierig: Glanzpunkt in den Augen, folgt dir
  • Verspielt: rote Bäckchen, kräftigere Farben, hüpft
  • Ängstlich: kleine Pupillen, Schweißtropfen, blasser

Antworte im Terminal mit der Nummer, gern mit Wünschen, zum Beispiel „Entwurf 3, aber in Grün“. Die Pixelkarten und Regeln stecken als JSON in dieser Seite und werden 1:1 ins Python-Overlay übernommen.
